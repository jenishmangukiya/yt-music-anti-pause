# YouTube Music Anti-Pause 🎵

A lightweight Tampermonkey script that automatically bypasses the annoying "Are you still listening?" prompt on YouTube Music, ensuring your playback never gets interrupted while you're working or focused.

## 🚀 Features
* Runs quietly in the background without impacting browser performance.
* Automatically detects and clicks the "Continue" button as soon as the prompt appears.
* Failsafe built-in to immediately resume playback if the video momentarily pauses.

## 🛠️ Installation

1. Install the [Tampermonkey](https://www.tampermonkey.net/) extension for your browser (Chrome, Firefox, Edge, Safari).
2. Click on the Tampermonkey extension icon and select **Dashboard**.
3. Go to the **Utilities** tab and paste the raw URL of the script, or simply click the link below:
   
   👉 **[Install the Script](https://github.com/jenishmangukiya/yt-music-anti-pause/raw/refs/heads/main/yt-music-anti-pause.user.js)** 

4. Click **Install** when Tampermonkey prompts you.
5. Refresh your YouTube Music tab.
